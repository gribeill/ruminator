## Editing a profile

- **Subjects:** positive relevance signals; add or refine topics as interests change.
- **Positive examples:** add paper titles, arXiv IDs or URLs, and a short note explaining what makes them relevant.
- **Deprioritize:** add unwanted topics or approaches, with a reason. Leave empty until there is actual feedback; these should inform ranking rather than hide papers.
- **Negative examples:** record recommendations that missed the mark, ideally with an arXiv ID and a reason. A negative example means *not relevant to this profile*, not that the paper is poor or reports a null result.

Scientifically interesting negative or null results remain welcome. No exclusions are assumed, and discovery picks should remain possible outside these profiles.
